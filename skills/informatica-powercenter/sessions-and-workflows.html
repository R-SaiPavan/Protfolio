PowerCenter roadmap / 03

Sessions and workflows

Configure runtime behavior and orchestrate dependencies so ETL runs are observable, restartable, and safe to operate.

SessionsWorkflow patternPractice

01 / Runtime configuration

A session connects a mapping to its run context.

Connections

Bind source and target connections through environment-appropriate configuration; avoid hard-coding environment secrets in objects.

Parameters and variables

Use parameter files or supported configuration to supply values such as dates, schemas, and file paths per environment or batch.

Session properties

Review commit behavior, error thresholds, tracing, partitioning, and recovery settings based on the source and target requirements.

Workflow dependencies

Define success, failure, and decision paths explicitly. Make dependencies reflect data readiness, not assumed timing.

02 / Example workflow

Stage, validate, publish.

Stage session

Load the batch into a staging target and record the batch identifier.

Validation task

Check required fields, row counts, and rejected records; branch to an alert path if thresholds fail.

Publish session

Run the target update only after validation succeeds, using a repeat-safe load strategy.

Completion and recovery

Record the final batch state and define which task can be restarted without repeating completed work.

03 / Practice

Interview checks.

What is configured in a session versus a workflow?

A session configures execution of a mapping, including connections and runtime properties. A workflow orchestrates sessions and tasks, dependencies, scheduling, and recovery paths.

How do parameter files help across environments?

They externalize values that change across environments or runs, such as connections or source paths, allowing the same reusable metadata to be configured safely.

How would you design a restartable workflow?

Track batch and task status, make steps idempotent, define success and failure transitions, and ensure restart points do not duplicate already-published data.
