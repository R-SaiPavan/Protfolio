# Portfolio Website

A responsive, standalone portfolio layout for Sai Pavan Rajulapati. It includes six sections: profile, education, work experience, awards, interview preparation (with seven skill links), and contact. Each skill has its own folder under `skills/`, with an `index.html` guide and separate topic pages. Shared learning-page styles and scripts are in `skills/shared/`.

The visual direction follows the supplied reference: a dark sidebar on desktop, a split profile introduction, and a stacked mobile layout.

## Open the page

Open `index.html` directly in a browser. The skill links inside Interview Preparation open their guide pages; each guide links to its topic pages in the same folder. No dependencies, build step, or development server are required.

## Personalize the sections

Replace the remaining labeled prompts with your details one section at a time. The supplied portrait is `Designer.jpg`; replace that file to use another photo. Date of birth and any remaining profile or project prompts are placeholders. Contact links use the details provided. Award details and certificate previews use the provided local image files. Only include personal information, such as your date of birth, that you want to share publicly. Interview Preparation links to seven skill guides; each guide follows the same roadmap, notes, and interview-practice format, with separate detail pages for its four roadmap topics.
